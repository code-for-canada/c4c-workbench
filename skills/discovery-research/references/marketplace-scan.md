# Marketplace Scan

What commercial software is on the market that could meet the partner's needs? We want the full range of possible options.


## Think creatively about the underlying need

The "obvious" product category may not be the best fit. For example, a monolithic government 'ERP' tool may be better served by a more modern commercial tool tailored to the specific problem, or a locked in Microsoft low code UI might be better solved with a third party tool that can connect via API.
Whatever the solution, a healthy tech ecosystem for most organizations requires user centric UIs, and interoperable foundations for using multiple tools together.

- What is the *underlying* problem that needs to be solved?
- Are there adjacent product categories that more modern organizations often move to for problems like this? 
- Are there modern entrants that have unbundled an older category for this problem?
- Are there options that play well in an 'ecosystem friendly' portfolio, and avoid vendor lock in?
(try a few search terms to dig up compelling start-ups and similar problem spaces and not just incumbents with SEO advantage)


## Canadian and open-source-aligned options

Always check for:

- Canadian vendors
- Hosted open-source options (e.g. managed deployments of OSS projects) where the underlying code is open even if the hosting is commercial

Avoid:
- Low code solutions that promise rich features but are slower than custom (now that AI development is fast)
- Only presenting legacy solutions that won't be justifiable in the future
- Include only options worth considering. Don't pad with tools that definitely don't fit.


## Output

For each result, capture:

> **[Name](link)** — one short sentence on strengths, weaknesses, and how well it solves the problem. Note any material risk surfaced during investigation.
